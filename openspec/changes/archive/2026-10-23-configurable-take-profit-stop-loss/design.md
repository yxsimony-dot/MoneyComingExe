## Context

动机见 `proposal.md`，可验收行为见本变更下的三份规格。

当前领域层由共享的 `EntryStrategySettings` 统一驱动方向反应、入场线、连续反向K线、休市离场和日期范围，但止损距离仍固定为红框高度的75%，默认止盈距离仍固定为红框高度的200%。选中事件图表、首轮与第二轮生命周期以及全盘盈亏复盘最终都会经过同一套生命周期计算，因此新增参数必须进入共享设置对象，而不能只由渲染层移动线段。

现有止盈信号同时保存默认止盈价和风险侧首次触碰后的调整止盈价。后者具有独立交易含义：多头调整到红框最高价，空头调整到红框最低价。本次只参数化默认止盈距离，不能让该特殊规则随参数漂移。

设置面板已经具备版本化本地存储、逐字段回退和统一刷新入口。自动化Electron、打包EXE、安装版和快捷方式GUI测试必须继续遵守首次显示前离屏定位以及窗口矩形与所有显示器均无面积交集的项目规则。

## Goals / Non-Goals

**Goals:**

- 用两个经过验证的百分比统一驱动首轮、第二轮、图表生命周期和全盘盈亏复盘。
- 保持75%止损和200%默认止盈时与现有价格结果完全一致。
- 对不能整除tick的距离统一向红框外侧补齐，保证多空严格镜像。
- 在现有策略设置面板中提供紧凑控件、字段级持久化、实时重算和只读理论默认盈亏比。
- 保持风险侧首次触碰后的特殊止盈价与既有事件优先级不变。

**Non-Goals:**

- 不修改60分钟信号、回调触发、方向反应搜索、红框边界、入场线、第二轮触发或休市规则。
- 不修改10倍理论名义杠杆、手数、手续费、滑点、日期范围或资金递推口径。
- 不提供小数百分比、任意1%步进、恢复默认按钮、参数历史、每品种独立参数或多设备同步。
- 不把后台1分钟K线显示在软件界面内。

## Decisions

### 1. 扩展现有共享策略设置对象

`EntryStrategySettings` 增加两个字段：

```ts
interface EntryStrategySettings {
  // existing fields...
  stopLossRangePercent: number;
  takeProfitRangePercent: number;
}
```

领域层同时定义各自的最小值、最大值、默认值和步长：

```text
止损距离:      0%..300%，默认75%，步长5%
默认止盈距离:  0%..500%，默认200%，步长5%
```

有效值必须是有限整数、位于边界内且能被5整除。生命周期、盈亏复盘和渲染层继续传递完整设置对象，避免图表使用新参数而复盘仍使用固定常量。

备选方案是只给止盈止损函数增加两个可选数字，但多条调用链容易漏传，并会绕开现有持久化和统一刷新机制，因此不采用。

### 2. 所有百分比距离先换算为整数tick并向外取整

令红框高度为 `R = high - low`，当前止损百分比为 `S`，默认止盈百分比为 `T`：

```text
rangeTicks = round(R / tick)
stopTicks = ceil(rangeTicks * S / 100)
targetTicks = ceil(rangeTicks * T / 100)

多头止损 = low - stopTicks * tick
空头止损 = high + stopTicks * tick

多头默认止盈 = high + targetTicks * tick
空头默认止盈 = low - targetTicks * tick
```

先在tick网格内计算可避免非1 tick品种产生非法价格。`ceil` 只补齐百分比距离：精确整除时不多加tick，不能整除时统一向红框外侧增加到下一个完整tick。0%合法，价格分别落在对应红框边界。

### 3. 默认止盈与风险侧特殊止盈保持两个独立价格

止盈信号继续保存：

```text
defaultPrice  = 使用当前T计算的默认止盈价
adjustedPrice = 多头红框最高价 / 空头红框最低价
```

真正入场后首次触碰红框风险侧边界时，仍按既有顺序切换到 `adjustedPrice`；`takeProfitRangePercent` 只改变 `defaultPrice`。这样参数变化不会破坏已经确认的“触底/触顶后收紧止盈”规则，也不会改变1分钟优先、5分钟保守回退的同根K线事件顺序。

### 4. 理论默认盈亏比只描述正常百分比入场模式

令当前入场线百分比为 `P`。在未触发方向侧影线风险边界覆盖、也未触发风险侧特殊止盈的理论条件下：

```text
风险距离 = (P + S) * R
收益距离 = (100 + T - P) * R
理论默认盈亏比 = 收益距离 / 风险距离
```

实现可直接使用百分比计算，红框高度会在比值中约掉。默认 `P=25`、`S=75`、`T=200` 时显示 `2.75:1`。当 `P + S = 0` 时不显示无穷大，而显示“不可计算”。

该指标只帮助用户理解当前参数组合的默认计划，不代表每一笔实际交易：方向侧影线可能把某轮入场价覆盖到风险侧边界，风险侧触碰也可能把止盈调整到红框另一侧，休市出场更可能产生不同结果。

### 5. 沿用现有存储键进行字段级兼容

继续使用 `moneycoming.entry-strategy-settings.v1`。加载时分别规范化两个新字段：

1. 有效值原样保留。
2. 字段缺失或单字段无效时，该字段分别回退到75或200。
3. 其他已有且有效的策略字段继续保留。
4. 规范化后的完整对象进入内存状态，并按现有持久化流程保存后续有效修改。

相比更换存储键，该方案无需维护双键迁移；相比整对象失败后全部恢复默认，它不会清除用户已经设置的入场线、K线浮动、反向数量、休市时间和日期范围。

### 6. 参数控件复用现有紧凑步进器

在“周一8根标记”的设置面板增加“止损距离”和“默认止盈距离”两组控件，每组包含减号按钮、数字输入框、加号按钮和百分号单位。按钮每次变化5%，在上下边界禁用。

输入框只在提交值为合法5%步长时更新设置；临时空白、小数、非5倍数、非数字或越界值不进入策略状态，失焦或按回车时恢复最近一次有效值。不增加“恢复默认”按钮。理论默认盈亏比作为只读摘要与参数组一起显示，并明确其为默认计划值。

面板继续随“周一8根标记”开关显示或隐藏，隐藏不改变已保存参数。窄窗口沿用现有换行布局，控件保持稳定尺寸且不得与日期范围或盈利摘要重叠。

### 7. 有效参数变化复用统一策略刷新

一次有效修改按现有统一入口完成：

1. 验证并保存完整策略设置。
2. 更新控件、页面诊断状态和理论默认盈亏比。
3. 保持当前品种、选中信号和用户缩放，重新计算首轮与第二轮完整生命周期。
4. 替换止盈止损线、风险侧标记、实际出场标记及受出场变化影响的其他策略元素。
5. 使用同一设置执行一次全盘盈亏复盘，更新面板盈利摘要。
6. 若“盈亏情况”已打开，复用同一结果刷新交易明细、资金曲线、统计和最终资金。

不能只局部移动止盈止损线，因为价格变化会改变实际出场类型、出场时间、第二轮启动时机以及后续逐笔资金。

### 8. 规则说明与测试共同锁定口径

应用内完整入场规则和外部规则文档同步说明参数范围、默认值、5%步长、多空公式、tick向外取整、两轮共用、实时重算和风险侧特殊止盈不受默认参数影响。理论默认盈亏比说明使用当前 `P/S/T`，并注明它不等同于每笔实际盈亏。

领域测试覆盖百分比边界、5%步长校验、非整tick距离、多空镜像、零距离、两轮独立红框、风险侧特殊止盈和分钟事件顺序。复盘测试覆盖出场类型、交易明细、资金曲线、统计和最终资金随参数变化一致更新。GUI测试覆盖默认值、旧存储迁移、持久化、实时刷新、弹窗已打开状态、窄窗口布局和理论比值，并统一通过 `tests/electron-test-launch.mjs` 离屏启动。

## Risks / Trade-offs

- [每次调节参数都可能触发全历史生命周期和复盘重算] -> 只提交真实发生的合法5%变化，复用一次复盘结果，并通过现有统一刷新入口避免重复计算。
- [0%止损或0%默认止盈可能让计划线与红框边界重合] -> 保持真实价格和独立线段语义，不人为偏移；通过标签、颜色和测试区分。
- [理论默认盈亏比可能被误认为实际策略盈亏比] -> 标题和说明明确“理论默认”，风险侧覆盖、特殊止盈和休市出场仍以实际复盘为准。
- [旧存储对象缺少新字段导致其他设置被重置] -> 对每个新旧字段分别规范化，并增加缺一项、两项都缺失和单字段损坏的升级测试。
- [调用点漏传设置导致图表和复盘结果分叉] -> 止盈止损计算从共享设置读取，并用同一行情与设置的图表/复盘一致性测试锁定。
- [向外取整在非1 tick品种上出现浮点误差] -> 先换算整数 `rangeTicks` 和距离tick数，再乘回价格步长并使用现有价格规范化方式。

## Migration Plan

1. 扩展共享策略设置、默认值、边界、步长校验和字段级加载兼容。
2. 让止损与默认止盈计算接收共享设置，并接入首轮、第二轮和所有直接调用点。
3. 补齐领域生命周期及全盘盈亏复盘测试，确认风险侧特殊止盈与事件顺序不变。
4. 增加两组参数控件和理论默认盈亏比，接入统一实时刷新及诊断状态。
5. 更新应用内与外部规则说明，并补齐规则一致性测试。
6. 运行类型检查、领域测试、完整测试、构建，并按项目离屏规范完成Electron与最新版EXE验收。

回滚时可隐藏新控件并在领域默认设置中固定75和200；存储对象中的额外字段可被旧逻辑忽略，不涉及行情、交易或资金数据迁移。
