## Context

MoneyComing 主进程创建 `BrowserWindow` 时使用 `show: false`，测试模式不会在 `ready-to-show` 阶段自动显示窗口。现有 Playwright/Electron 烟雾测试取得窗口后分别调用 `showInactive()` 或 `show()`，因此窗口会按 Electron 默认位置出现在可见桌面。Windows 快捷方式验收则以普通窗口方式直接启动打包 EXE。

该约束横跨主进程、多个 JavaScript 烟雾测试、性能测试和 PowerShell 快捷方式验收。详见 `proposal.md`，行为要求见 `specs/offscreen-exe-testing/spec.md`。

## Goals / Non-Goals

**Goals:**

- 在窗口首次可见前计算并应用完全位于所有显示器之外的位置。
- 让开发态 Electron、打包 EXE、性能测试和快捷方式验收使用同一几何规则。
- 对实际窗口边界执行自动断言，防止操作系统位置修正导致窗口重新落入显示器。
- 保持现有测试的渲染、截图、交互、焦点和任务栏行为。

**Non-Goals:**

- 不隐藏任务栏图标，不强制禁止抢占焦点，也不统一 `show()` 与 `showInactive()`。
- 不改变普通用户启动时的窗口尺寸、位置或记忆策略。
- 不处理测试运行期间热插拔显示器或动态修改显示器排列的情况。
- 不将 GUI 验收改造成无头测试。

## Decisions

### 1. 使用所有显示器的最右边界计算屏幕外位置

主进程在 Electron 已就绪后读取所有显示器边界，计算 `max(display.x + display.width)`，并把测试窗口左边界设置到该值之外的固定安全间距。纵坐标沿用主显示器工作区起点。

把完整窗口放到虚拟桌面最右侧之外，比使用固定负坐标更可靠：显示器可能位于主屏左侧并具有负坐标，而最右边界之外不会与任何已枚举显示器相交。Electron 的显示器边界和窗口边界使用相同的 DIP 坐标体系，不需要自行换算缩放比例。

备选方案是创建窗口后再调用 `setPosition()`。该方案可能产生窗口先在中央显示再移动的闪现，不满足首次显示前完成定位的要求。

### 2. 在主进程窗口创建路径集中应用位置

主进程通过现有自动化测试模式或显式的测试专用命令行标记识别离屏启动，并在构造 `BrowserWindow` 时提供计算后的坐标。普通启动不提供这些坐标，继续使用 Electron 的默认行为。

Playwright 启动路径继续使用现有测试环境变量。快捷方式验收为其临时创建的测试快捷方式增加测试专用命令行标记，使该路径保持普通产品配置的其余行为，同时在窗口创建前启用离屏定位。

备选方案是在每个测试脚本中重复移动窗口。该方案容易遗漏新测试，也无法可靠覆盖直接通过快捷方式启动的窗口。

### 3. 提取可测试的矩形相交与目标位置计算

显示器矩形联合边界、目标坐标和矩形相交判断应放在无 Electron 状态依赖的纯函数中，并用单元测试覆盖单屏、多屏、负坐标、不同缩放后的 DIP 尺寸和非规则排列。

测试通过“窗口矩形与每个显示器矩形均无面积交集”判断是否完全离屏，而不是只检查窗口左上角。边界相接但没有面积交集可视为离屏。

### 4. 在各 GUI 验收入口验证实际窗口位置

Playwright/Electron 测试使用共享助手读取实际 `BrowserWindow` 边界和显示器列表，并在窗口显示前后至少验证一次完全离屏。现有各烟雾测试和性能测试复用该助手，但保留各自当前的窗口显示方法。

PowerShell 快捷方式验收在取得主窗口句柄后读取实际窗口矩形，并与当前所有显示器逐一比较。若无法读取窗口矩形或发生交集，测试明确失败并在清理阶段只关闭本次启动的进程。

### 5. 不增加焦点和任务栏控制

实现不新增 `setSkipTaskbar()`、强制最小化或焦点恢复逻辑。现有测试使用 `showInactive()` 的地方可以继续使用，性能测试现有的 `show()` 也可以保留；这些行为不属于离屏能力的验收条件。

## Risks / Trade-offs

- [操作系统可能修正极端窗口坐标] -> 在实际显示前后读取最终窗口边界并执行相交断言，发现修正时立即让测试失败。
- [离屏但仍激活的窗口可能接收键盘输入] -> 这是用户明确允许的行为；测试应避免依赖全局键盘输入，继续使用 Playwright 定向交互。
- [测试异常退出可能留下离屏进程] -> 保留并检查各测试的 `finally` 清理逻辑，只终止本次测试拥有的进程。
- [快捷方式增加测试参数与用户快捷方式不完全相同] -> 参数只控制窗口几何位置，不改变目标 EXE、工作目录、数据加载或其他产品行为。

## Migration Plan

1. 增加离屏坐标计算与矩形相交的纯函数及单元测试。
2. 将测试模式和测试专用启动标记接入主进程窗口创建选项。
3. 增加共享 Electron 测试断言并迁移现有 GUI 烟雾测试与性能测试。
4. 更新快捷方式验收的启动参数和实际窗口矩形断言。
5. 运行单元测试、类型检查、生产构建、开发态烟雾测试、打包 EXE 与快捷方式验收。

回滚时移除测试专用坐标与启动标记，并让测试恢复原有窗口启动方式；不涉及用户数据或配置迁移。
