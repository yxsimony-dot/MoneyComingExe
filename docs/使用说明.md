# MoneyComing 豆粕历史看盘

这是离线历史行情查看器。安装包内置数据截至2026年10月9日15:00，运行后可按需增量更新。

## 启动

从本项目的正式 GitHub Release 下载 `MoneyComing-Setup-<版本>-x64.exe`，运行安装程序并按提示完成安装。安装后从桌面或开始菜单启动 MoneyComing。无需安装 Python 或 Node.js。

旧 ZIP 版用户需要手动运行一次 NSIS 安装程序；旧目录不会自动覆盖或迁移。完成首次安装后，后续正式版本可通过应用内更新。

## 应用更新

- 应用窗口可用后会在后台检查一次更新，不会阻塞本地行情和图表加载。
- 点击右上角版本号可手动检查，并查看“正在检查”“已是最新版本”“发现新版本”或失败信息。
- 发现新版本后，选择“稍后”不会下载或退出；只有选择“立即下载”才会开始下载。
- 下载完成后仍可继续看盘；只有选择“重启安装”才会退出当前版本并启动安装程序。
- 离线、GitHub 暂时不可用、下载中断或校验失败时，当前版本和本地数据仍可正常使用，可稍后重试。

当前发布若未配置代码签名，Windows SmartScreen 可能显示“未知发布者”。请核对安装包来自 `yxsimony-dot/MoneyComingExe` 的正式 GitHub Release，文件名应为 `MoneyComing-Setup-<版本>-x64.exe`。不要从聊天附件或不明网盘安装。

## 行情更新

- 点击工具栏“更新行情”，程序会从 EDB 增量获取豆粕主连历史分钟数据，校验后重建5分钟和60分钟K线。这不是实时行情推送，也不会接入新浪或其他数据源。
- EDB 可能尚未发布当前自然日的完整数据。界面显示的“数据源最新至 YYYY-MM-DD HH:mm”是本次能够取得的实际截止时间，不代表已经更新到今天。
- 更新成功后，程序把版本化行情快照保存到当前用户的 AppData，并在后续启动时优先加载。安装或升级应用不会用安装包中较旧的内置基线覆盖该快照。
- 网络、下载、解析、校验或保存失败时，界面会提示“更新失败”和“当前数据未受影响”。程序继续使用此前有效快照，可以稍后重试。
- “最新”按钮与“更新行情”互相独立。“最新”只把两个周期的图表跳到当前本地数据末尾，不发起网络请求；更新行情成功时也不会强制把正在查看的历史位置跳到末尾。

## 看图

- 顶部仅保留豆粕主连。默认左侧60分钟、右侧5分钟，可切换单图。
- 60分钟主图默认叠加浅白色EMA20曲线，光标读数中显示对应EMA20数值。采用指数移动平均：本根EMA = 本根收盘价×2/21 + 上根EMA×19/21；以当前数据集首根收盘价初始化，包含当前K线，跨日跨周连续计算。它不是最近20根的算术平均；初始数据不同的软件在样本前段可能存在差异。隐藏副图或周一标记不会隐藏EMA20。
- 点击工具栏“只看K线”隐藏成交量和持仓量副图，K线会占满图表区域；点击“显示副图”恢复。两个周期同步切换，切换布局时保留当前显示状态。
- 鼠标滚轮缩放，按住左键拖动历史。十字光标显示价格、成交量、持仓量与持仓变化。
- 点击60分钟K线定位对应5分钟区间；点击5分钟定位所属60分钟。
- “周一8根标记”按钮默认关闭，点击显示，再次点击隐藏；切换布局时保留开关状态。开启后，60分钟图中从每个北京时间周一的第一根开始，连续8根K线使用金色边框、影线和圆点高亮；因此通常会覆盖周一6根并延续到周二上午2根。5分钟图不添加此标记。
- 同一个按钮也控制逐次突破标记：前8根的最高价、最低价形成初始范围，从第9根起，影线严格超过此前周内最高点时显示蓝色向上箭头，严格低于此前周内最低点时显示紫色向下箭头。每次突破都更新对应边界；仅越过初始范围但没有创出新极值的后续K线不重复标记，相等也不标记。同一根可同时标记两个方向。
- 同一个按钮还显示回调入场标记：绿色“多”表示向上突破后首次有效回调，珊瑚色“空”表示向下突破后首次有效反弹。中点按周内动态最高、最低计算；做多回调线取中点与EMA20较低者，做空取较高者。反向突破取消旧方向，同方向新极值重新等待一次。影线触线即算。
- 同一60分钟内的先后按组成5分钟K线判断；必须先突破、后触线。突破与触线落在同一根5分钟时顺序无法确认，本次不入场。判断使用该5分钟之前最近完成的60分钟EMA20，避免使用尚未收盘的未来数据。缺少完整5分钟组成记录时不推测入场。
- 鼠标移到突破K线上，可查看“原边界 → 新边界”。每个北京时间自然周重新计算；无周一记录的周不启用，不足8根时不判断突破。源价格保持原值并参与计算。
- 点击“入场规则”可在程序内查看完整规则。说明来自EXE同级 `data/entry-rules.md`，编辑后重新打开弹窗即可刷新文字；编辑文字不会自动修改标记算法，算法变化仍需更新并重新验收程序。
- 输入北京时间自然日后点击定位。休市日定位之后第一条，超出范围定位到数据边界并提示。
- 点击“最新”返回当前本地快照的末尾；这不是实时行情刷新，也不会触发“更新行情”。

## 数据口径

行情源为EDB。安装包内置基线包含豆粕主连5分钟16530根、60分钟1438根；执行“更新行情”后，以界面显示的当前快照数量和“数据源最新至”时间为准。

60分钟按实际交易分钟累计，跳过休息。日盘最后一根有45个交易分钟，因此对应9根5分钟。时间均为北京时间自然日期，夜盘没有擅自改成次交易日。

主连保留源价格，没有自行复权。持仓是该根结束时的持仓量，不是累计成交量。

## 数据审计

交付的审计元数据验证豆粕主连原始1分钟数据与5分钟、60分钟聚合结果的一致性；当前没有记录需要在图表中提示的已知异常。完整性标记只表示组成分钟齐全。

## 文件错误

安装目录中的data目录缺失或内置CSV损坏时，界面会显示文件名与原因，可重新安装正式版本后点击重试。用户 AppData 中的当前快照无效时，程序会尝试上一个完整快照，仍不可用时再回退到安装包内置基线。缺少可选审计资料时仍可看行情，但异常提示不可用。

程序只在“更新行情”成功后写入用户 AppData 快照，不会修改安装目录中的内置行情文件。初版为本地未签名构建。第三方组件许可见 THIRD-PARTY-NOTICES.txt。

入场标记是对本地历史数据按约定规则进行的复盘标注，不构成交易建议，也不会发出订单。

## 卸载

可在 Windows“设置 → 应用 → 已安装的应用”中卸载 MoneyComing，也可使用开始菜单中的卸载入口。卸载应用不会主动删除用户目录中的行情增量快照。
