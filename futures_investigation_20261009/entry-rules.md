# 每周突破回调入场规则

本规则适用于软件内的十五个主连品种：豆粕、菜粕、PVC、螺纹钢、玻璃、菜油、棕榈油、豆油、纸浆、玉米、纯碱、豆一、甲醇、白糖和豆二。每个品种使用自身的最小变动价位、合约乘数、交易时段和主力换月记录；单一交割合约不作为独立可选数据分支。

1. 适用周期：界面只显示60分钟和5分钟K线。60分钟K线保留既有“多/空”回调触发事件；真正入场位置在对应的5分钟观察窗口内判断和标记，1分钟数据仅在后台用于精确事件排序。
2. 每周范围：从北京时间周一第一根开始，第1至第8根的最高价和最低价（包含影线）形成初始范围。无周一记录或不足8根的周不产生入场标记。
3. 突破：从第9根起，影线严格超过此前周内最高点为向上突破，严格低于此前周内最低点为向下突破，相等不算突破。
4. 动态范围：周内最高价H、最低价L持续更新；中点M=(H+L)/2。新极值出现后，回调线按最新H、L重新计算。
5. 做多：向上突破后等待向下回调；做多回调线为中点M与60分钟EMA20中较低者，即 min(M, EMA20)。
6. 做空：向下突破后等待向上反弹；做空回调线为中点M与60分钟EMA20中较高者，即 max(M, EMA20)。
7. 触线：影线碰到回调线就算，恰好相等也算，不要求收盘确认。既有“多/空”事件标记画在触线所属的60分钟K线上，该事件是后续5分钟入场判断的起点。
8. 首次回调：一次突破只标第一次有效回调；入场后该方向等待结束。该方向再次创出新高或新低后，重新等待一次入场。
9. 反向突破：向上突破取消当前等待做空，改为等待做多；向下突破取消当前等待做多，改为等待做空。多空不同时保留等待状态。
10. 5分钟顺序：按组成5分钟K线的时间顺序确认。必须先突破、后触线，才产生入场标记。
11. 同一5分钟极端情况：如果突破和触线发生在同一根5分钟K线内，无法判断先后，则跳过这次入场，不显示标记；后续仍按新的等待方向继续判断。
12. 同一60分钟内反向：如果一小时内先上破后下破，最终等待做空；先下破后上破，最终等待做多。顺序以5分钟K线为准。
13. 每周重置：进入下一北京时间自然周后，范围和等待状态清除；EMA20跨周连续计算。
14. 数据边界：缺少完整5分钟组成记录或无法复原事件顺序的小时不产生入场标记；原始数据不修改。
15. 5分钟完整生命周期：选中既有60分钟入场事件后，从实际触发回调线的5分钟K线开始，使用同一北京时间日期、同一日盘或夜盘内实际存在的后续K线继续分析，不再以“触发K线及后续15根”为分析上限，也不得跨到下一交易日期或另一交易时段。
16. 日夜盘边界：日盘新入场截止时间为14:45、自然休市时间为15:00、强制出场K线为14:40-14:45；夜盘新入场截止时间为22:45、自然休市时间为23:00、强制出场K线为22:40-22:45。14:40或22:40开始的K线仍可产生真正入场，14:45或22:45开始及之后的K线禁止新入场。
17. 未入场休市：截止时间后仍可继续形成红框和显示计划线，但不得产生真正入场，也不得启动止盈止损。若到15:00或23:00始终没有真正入场，生命周期在该时段最后一根实际K线结束，不生成任何止盈、止损或休市出场标记。
18. 持仓休市出场：已入场持仓最多分析到14:40-14:45或22:40-22:45强制出场K线并包含该根。系统先判断该根内部是否止盈或止损；若整根处理后仍持仓，则以该根5分钟K线收盘价生成唯一的“休市出场”。
19. 点击定位范围：完整生命周期用于计算和绘制；点击60分钟入场事件后的初始5分钟视口仍只使用触发附近最多16根的紧凑范围，并继续同步左侧当前缩放比例，不会因完整生命周期变长而压扁K线。视口外的后续线段和标记可通过平移查看。
20. 5分钟动态回调线：完整生命周期内逐根绘制绿色实线。做多时每根取“原回调线与该根5分钟EMA20孰低”，即 min(回调线, 5分钟EMA20)；做空时每根取二者孰高，即 max(回调线, 5分钟EMA20)。
21. 多头首次反应范围：最小入场K线浮动由“周一8根标记”参数面板的当前整数N控制，N可设为1至20 tick；首次没有有效历史设置时默认为1 tick，之后保存最后一次有效值并在软件重启后继续使用。从触发K线本身开始，按时间顺序寻找第一根实体上涨至少N个tick的5分钟K线，即满足 `close - open >= N × tick`；实体正好等于N个tick也合格，实体不足、十字星和下跌K线都不能结束搜索。实体达标后只计算方向侧上影线 `high - close`，下影线不参与影线倍数判断。上影线小于实体2倍时，该K线是使用当前入场线百分比的正常反应K线；上影线大于等于实体2倍且小于实体3倍时，该K线仍是有效反应K线，但本轮白线强制使用红框风险侧边界；正好2倍属于风险侧入场。上影线大于等于实体3倍时必须跳过并继续寻找，正好3倍也必须跳过。红框在最终合格上涨K线结束后确定：上沿只取该最终上涨K线最高价；下沿取从触发K线开始、到该上涨K线为止且包括两端的所有K线最低价。实体不足或因3倍上影线被跳过的K线仍参与红框最低价统计。
22. 空头首次反应范围：使用与多头和第二轮相同的当前参数N。从触发K线本身开始，按时间顺序寻找第一根实体下跌至少N个tick的5分钟K线，即满足 `open - close >= N × tick`；实体正好等于N个tick也合格，实体不足、十字星和上涨K线都不能结束搜索。实体达标后只计算方向侧下影线 `close - low`，上影线不参与影线倍数判断。下影线小于实体2倍时，该K线是使用当前入场线百分比的正常反应K线；下影线大于等于实体2倍且小于实体3倍时，该K线仍是有效反应K线，但本轮白线强制使用红框风险侧边界；正好2倍属于风险侧入场。下影线大于等于实体3倍时必须跳过并继续寻找，正好3倍也必须跳过。红框在最终合格下跌K线结束后确定：下沿只取该最终下跌K线最低价；上沿取从触发K线开始、到该下跌K线为止且包括两端的所有K线最高价。实体不足或因3倍下影线被跳过的K线仍参与红框最高价统计。
23. 红框边界：多头红框从产生上述最低价的K线开始，到首次上涨K线结束；空头红框从产生上述最高价的K线开始，到首次下跌K线结束。若首次反应K线自身产生该极值，红框的左右边界都落在该首次反应K线上；若触发K线本身就是首次反应，红框同样只覆盖该根K线。生命周期内没有对应方向的首次反应时不画红框，也不读取生命周期外K线。
24. 范围含义：该范围表示价格触及回调区域后形成的第一次方向性反应范围，也是计算5分钟白色入场指标线、计划止损线和计划止盈线的唯一价格范围。
25. 入场线百分比：当前入场线百分比P为0至100之间的整数，可在“周一8根标记”参数面板中按1%步长调节。首次没有有效历史设置时默认25%，之后保存最后一次有效值并在软件重启后继续使用；首轮和第二轮共享同一个P。最终方向反应K线的方向侧影线小于实体2倍时，先计算 `rangeTicks = round((最高价 - 最低价) / tick)`，再计算 `entryDistanceTicks = ceil(rangeTicks × P / 100)`；百分比距离不能落在完整tick时向上补齐一个tick，正好为整数tick时不额外增加。
26. 多空镜像与位置含义：正常百分比模式下，多头白线价格为 `最低价 + entryDistanceTicks × tick`，空头白线价格为 `最高价 - entryDistanceTicks × tick`。P=0时白线位于多头红框最低价或空头红框最高价；P=25时保持原25%位置；P=100时白线位于多头红框最高价或空头红框最低价。例如最低价3020、最高价3031、tick为1且P=25时，距离2.75 tick向上取为3 tick，因此多头白线为3023，空头白线为3028。方向侧影线大于等于实体2倍且小于实体3倍时，本轮忽略P并把实际 `entryDistanceTicks` 设为0，使多头白线位于红框最低价、空头白线位于红框最高价；该覆盖只影响本轮实际入场价，不修改或持久化用户保存的P，其他正常反应轮次仍继续使用该P。
27. 白线范围：白色入场指标线使用实线，从红框左边界对应的5分钟K线开始，延伸到本次生命周期终点并包含终点K线；实际止盈、止损或休市出场后立即停止，不越过终点。每条实际存在的白线都在5分钟图右侧价格轴显示“入场”和对应价格，白线不参与价格轴自动缩放。
28. 搜索起点与截止：真正入场搜索从首次方向反应K线的下一根5分钟K线开始，首次反应K线本身即使覆盖白线也必须排除。候选K线的开始时间必须早于日盘14:45或夜盘22:45，等于或晚于截止时间的触碰只保留观察含义，不算真正入场。
29. 触碰与入场：合格候选K线满足 `low <= 白线价格 <= high` 即视为触碰，实体、上影线、下影线或刚好相等都有效。只把按时间顺序第一根合格触碰白线的K线标记为“入场”，后续重复触碰不再增加标记。
30. 三阶段含义：完整顺序是“回调触发 -> 首次方向反应范围与影线分类 -> 本轮实际白色入场线首次合格触碰即真正入场”。本轮实际白线可能来自当前百分比，也可能因方向侧影线大于等于实体2倍且小于实体3倍而位于红框风险侧边界。60分钟突破、回调事件、数量、所属K线和原标记位置不因5分钟真正入场结果而改变。
31. 止损生成时机：首次方向反应红框形成后，立即同时得到白色入场指标线和明黄色计划止损线。黄色线不等待白线被触碰；即使生命周期内没有真正入场K线，只要红框存在，黄色线和白线都继续保留到生命周期终点。
32. 止损距离：沿用红框的最高价、最低价和当前标的tick，先计算 `rangeTicks = round((最高价 - 最低价) / tick)`，再计算 `stopTicks = ceil(rangeTicks × 0.75)`，止损距离为 `stopTicks × tick`。75%能够得到完整tick时不额外增加tick；不能得到完整tick时向上补齐一个tick。
33. 止损多空镜像：多头止损价为 `最低价 - stopTicks × tick`；空头止损价为 `最高价 + stopTicks × tick`。例如最低价3020、最高价3031且tick为1时，范围为11个tick，75%为8.25并向上补齐为9个tick，因此多头止损为3011，空头止损为3040。
34. 黄色线范围：计划止损线使用颜色 `#f4c95d` 的2像素明黄色实线，从红框左边界对应的5分钟K线开始绘制，并延伸到本次生命周期终点且包含终点K线。黄色线不参与价格轴自动缩放，因此止损价可能暂时位于当前视口外，可通过既有右侧价格轴交互查看真实价格位置。
35. 实际止损：只有真正入场后才检测止损。多头满足 `low <= 计划止损价`、空头满足 `high >= 计划止损价` 即视为触碰，影线、实体、越过边界或刚好相等都有效；实际止损出场价固定取计划止损线价格，不取K线越过后的极值。
36. 止盈生成时机：首次方向反应红框形成后立即显示默认计划止盈线，不等待白色入场线被触碰。即使生命周期内没有真正入场K线，只要红框存在，默认止盈线就保留；没有真正入场时不检测风险侧、止盈或止损，也不生成实际出场。
37. 默认止盈距离：沿用红框的最高价、最低价和当前标的tick，先计算 `rangeTicks = round((最高价 - 最低价) / tick)`，再计算 `targetTicks = rangeTicks × 2`。多头默认止盈价为 `最高价 + targetTicks × tick`；空头默认止盈价为 `最低价 - targetTicks × tick`。例如最低价3020、最高价3031且tick为1时，范围为11个tick、止盈距离为22个tick，因此多头默认止盈为3053，空头默认止盈为2998。
38. 后台1分钟数据：程序会尽量加载、保存并持续累积能够取得的1分钟K线，用于判断同一根5分钟K线内部的真正入场、风险侧触碰、止盈和止损先后。1分钟数据只作为后台判断依据，不显示1分钟图表、周期按钮或可见数据面板。
39. 分钟完整性与逐根回退：每根参与判断的5分钟K线必须恰好对应5根唯一、连续、有序的1分钟K线，且聚合后的OHLC与该5分钟K线一致，才使用1分钟顺序。任一条件不满足时，丢弃该根的部分分钟证据，只对该根使用5分钟保守规则；下一根5分钟K线重新独立验证，完整时可以恢复1分钟判断。
40. 持仓检测起点：真正入场K线拥有完整分钟覆盖时，从该K线内第一根触碰白色入场线的1分钟K线开始持仓检测，该分钟之前发生的风险侧、止盈或止损触碰全部忽略。真正入场K线分钟覆盖不完整时，从整根真正入场5分钟K线开始按保守规则检测。
41. 首次风险侧调整：真正入场后，多头首次满足 `low <= 红框最低价` 为触底，并把止盈目标调整为红框最高价；空头首次满足 `high >= 红框最高价` 为触顶，并把止盈目标调整为红框最低价。只记录第一次有效触碰，后续重复触碰不再调整目标。若较早分钟先完成风险侧调整、同一根5分钟K线内较晚分钟再触及调整后止盈价，允许在较晚分钟止盈出场。
42. 保守事件优先级：在同一根1分钟K线或回退使用的同一根5分钟K线内无法判断价格先后时，按以下顺序处理：尚未入场时先确认白线触碰；入场与止损同单元发生则确认入场后立即止损；持仓后止损与任何其他事件同单元发生时止损优先；首次风险侧与止盈同单元且没有止损时只调整目标、不在该单元止盈；入场与止盈同单元且没有止损时也不在该单元止盈。
43. 实际止盈：真正入场后，多头满足 `high >= 当前止盈价`、空头满足 `low <= 当前止盈价` 即视为触碰，影线、实体、越过边界或刚好相等都有效；实际止盈出场价固定取触发时有效的计划止盈线价格。风险侧尚未触碰时使用默认目标，触碰后使用调整目标。
44. 单轮第一处实际出场：程序从每一轮的持仓检测起点按时间顺序扫描，该轮只记录第一处“止盈出场”“止损出场”或“休市出场”，随后立即结束该轮持仓和该轮计划线。首轮实际出场不一定结束整个60分钟事件，满足二次观察条件时仍可继续寻找第二轮。
45. 二次观察开启：只有首轮已经发生真正入场并生成实际出场，才从首轮出场K线的下一根5分钟K线开始观察第二轮；首轮出场K线自身必须排除，不能同时作为二次触发。首轮未真正入场或已经入场但尚未实际出场时，不创建第二轮。
46. 二次触发：二次观察期间，多头选择第一根满足 `low <= 首轮红框最低价` 的5分钟K线，空头选择第一根满足 `high >= 首轮红框最高价` 的5分钟K线。影线触碰、穿过和刚好相等都有效，不要求收盘确认。该K线只显示中性灰色“二次触发”标记，不代表真正入场，也不绘制首轮红框边界延长线。
47. 第二轮反应范围：二次触发K线自身参与方向反应搜索和极值统计，并使用与首轮相同的当前参数N、包含式实体门槛和方向侧影线规则。多头实体为 `close - open` 且只检查上影线 `high - close`，空头实体为 `open - close` 且只检查下影线 `close - low`，反方向影线不参与判断。方向侧影线小于实体2倍时使用当前百分比；大于等于实体2倍且小于实体3倍时使用本轮红框风险侧边界；大于等于实体3倍时跳过并继续搜索，因此正好2倍进入风险侧模式、正好3倍被过滤。实体不足或因3倍影线被过滤的K线仍参与从二次触发K线到最终合格反应K线的完整风险侧极值统计；第二轮盈利侧边界仍只取最终合格反应K线的高点或低点。
48. 第二轮入场和出场：第二轮根据自己的最终方向反应K线独立决定使用当前百分比或风险侧边界，不继承首轮的影线分类；特殊风险侧覆盖也不修改用户保存的入场线百分比。第二轮真正入场仍从方向反应K线的下一根5分钟K线开始寻找，并基于第二轮红框独立计算白色入场线、黄色止损线、亮蓝色止盈线、风险侧调整和实际出场。第二轮完整复用既有价格公式、tick取整、1分钟优先、5分钟保守回退、14:45/22:45新入场截止和休市强制出场规则。
49. 最多两轮：每个60分钟回调事件最多包含首轮和第二轮。第二轮红框形成后即锁定，不因后续再次突破而重建；第二轮实际出场后整个事件立即结束。即使第二轮只有二次触发或红框而未真正入场，时段结束后也不得创建第三轮或第四轮。
50. 盈亏复盘：首轮和第二轮只要发生真正入场，就分别作为独立交易计入逐笔列表、交易次数、出场类型、胜负、资金曲线和汇总统计。初始资金为1,000,000元，使用10倍理论名义杠杆；整数手数按 `floor(入场时可用资金 × 10 / (入场价 × 当前品种合约乘数))` 计算。多头现金盈亏为 `(出场价 - 入场价) × 合约乘数 × 手数`，空头为 `(入场价 - 出场价) × 合约乘数 × 手数`。第二笔入场使用包含第一笔已实现盈亏的可用资金；只有二次触发或第二轮红框但未真正入场时不计为交易。本复盘不使用实际保证金率，且不计手续费和滑点。
51. 强制出场优先级：在14:40-14:45或22:40-22:45强制出场K线内，完整1分钟证据优先；分钟不完整时使用既有5分钟保守规则。止盈或止损优先于休市出场，只有整根K线处理后仍持仓时才按收盘价休市出场。
52. 出场标记：每轮第一处实际出场所在的5分钟K线显示“止盈出场”“止损出场”或紫色“休市出场”。如果止损与“触底”或“触顶”落在同一根5分钟K线上，只保留“止损出场”，避免标记文字重叠；较早K线已经发生的风险侧标记仍保留。
53. 计划线终止：计划止盈线使用颜色 `#4fc3f7` 的2像素亮蓝色阶梯实线，首次风险侧触碰之前显示默认目标、从有效触碰K线开始显示调整目标。每轮止盈线与止损线共用该轮终点，均截止到该轮实际出场、时段结束或当前数据末尾并包含终点K线；两条计划线都不参与价格轴自动缩放。
54. 整体与单轮终点：绿色动态回调线和方向观察标记延伸到整个60分钟事件的生命周期终点。首轮红框和结果标记在首轮出场后保留，但首轮白色、黄色和亮蓝色计划线停止于首轮出场K线；第二轮元素使用自己的起点和终点。第二轮实际出场、自然休市或当前数据末尾结束整体生命周期。
55. 数据末尾：若实际数据尚未覆盖强制出场K线或自然休市末根，只分析到最后一根实际存在的K线并保持“数据暂未覆盖生命周期终点”，不得补造未来K线、二次触发、入场或出场。已经真正入场但尚未出场的任一轮保留为未完成交易。
56. 选择生命周期：切换60分钟入场事件时重新计算最多两轮的完整生命周期、真正入场、风险侧和实际出场；切换数据集、进入普通周期联动、回到最新或清除选择时，两轮红框、计划线、方向标记、二次触发、风险侧标记、出场标记和生命周期诊断一并清除，不得残留到其他事件。
