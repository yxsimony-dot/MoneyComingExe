# 每周突破回调入场规则

1. 适用周期：60分钟K线保留既有“多/空”回调触发事件；真正入场位置在对应的5分钟观察窗口内判断和标记。
2. 每周范围：从北京时间周一第一根开始，第1至第8根的最高价和最低价（包含影线）形成初始范围。无周一记录或不足8根的周不产生入场标记。
3. 突破：从第9根起，影线严格超过此前周内最高点为向上突破，严格低于此前周内最低点为向下突破，相等不算突破。
4. 动态范围：周内最高价H、最低价L持续更新；中点M=(H+L)/2。新极值出现后，回调线按最新H、L重新计算。
5. 做多：向上突破后等待向下回调；做多回调线为中点M与60分钟EMA20中较低者，即 min(M, EMA20)。
6. 做空：向下突破后等待向上反弹；做空回调线为中点M与60分钟EMA20中较高者，即 max(M, EMA20)。
7. 触线：影线碰到回调线就算，恰好相等也算，不要求收盘确认。既有“多/空”事件标记画在触线所属的60分钟K线上，该事件是后续5分钟入场判断的起点。
8. 首次回调：一次突破只标第一次有效回调；入场后该方向等待结束。该方向再次创出新高或新低后，重新等待一次入场。
9. 反向突破：向上突破取消当前等待做空，改为等待做多；向下突破取消当前等待做多，改为等待做空。多空不同时保留等待状态。
10. 5分钟顺序：按组成5分钟K线的时间顺序确认。必须先突破、后触线，才产生入场标记。
11. 同一5分钟极端情况：如果突破和触线发生在同一根5分钟K线内，无法判断先后，则跳过这次入场，不显示标记；后续仍按新的等待方向继续判断。
12. 同一60分钟内反向：如果一小时内先上破后下破，最终等待做空；先下破后上破，最终等待做多。顺序以5分钟K线为准。
13. 每周重置：进入下一北京时间自然周后，范围和等待状态清除；EMA20跨周连续计算。
14. 数据边界：缺少完整5分钟组成记录或无法复原事件顺序的小时不产生入场标记；原始数据不修改。
15. 5分钟观察窗口：选中既有60分钟入场事件后，从实际触发回调线的5分钟K线开始，连续观察该触发K线及后续15根K线，最多共16根；数据末尾不足时只使用实际存在的K线。
16. 5分钟动态回调线：观察窗口内逐根绘制实线。做多时每根取“原回调线与该根5分钟EMA20孰低”，即 min(回调线, 5分钟EMA20)；做空时每根取二者孰高，即 max(回调线, 5分钟EMA20)。
17. 多头首次反应范围：从触发K线本身开始，寻找观察窗口内第一根收盘价严格高于开盘价的上涨K线。范围上沿取该上涨K线最高价；范围下沿取触发K线至上涨K线之前所有K线的最低价。若触发K线本身就是上涨K线，则下沿取其自身最低价。十字星不算上涨K线。
18. 空头首次反应范围：从触发K线本身开始，寻找观察窗口内第一根收盘价严格低于开盘价的下跌K线。范围下沿取该下跌K线最低价；范围上沿取触发K线至下跌K线之前所有K线的最高价。若触发K线本身就是下跌K线，则上沿取其自身最高价。十字星不算下跌K线。
19. 红框边界：多头红框从产生前置最低价的K线开始，到首次上涨K线结束；空头红框从产生前置最高价的K线开始，到首次下跌K线结束。若触发K线本身就是首次反应，红框只覆盖该根K线。观察窗口内没有对应方向的首次反应时不画红框，也不读取窗口外K线。
20. 范围含义：该范围表示价格触及回调区域后形成的第一次方向性反应范围，也是计算5分钟四分之一白色入场指标线的唯一价格范围。
21. 四分之一距离：先按一个tick为1计算 `rangeTicks = round((最高价 - 最低价) / tick)`，再计算 `quarterTicks = ceil(rangeTicks / 4)`。能被4整除时不额外增加tick；不能整除时只把四分之一距离向上补齐到下一个完整tick。
22. 多空镜像：多头白线价格为 `最低价 + quarterTicks × tick`；空头白线价格为 `最高价 - quarterTicks × tick`。例如最低价3020、最高价3031时，范围为11个tick，四分之一2.75向上取为3个tick，因此多头白线为3023，空头白线为3028。
23. 白线范围：白色入场指标线使用实线，从红框左边界对应的5分钟K线开始，延伸到原观察窗口最后一根实际存在的K线；数据末尾不足16根时不补造K线。白线不参与价格轴自动缩放。
24. 搜索起点：真正入场搜索从首次方向反应K线的下一根5分钟K线开始。首次反应K线本身即使覆盖白线也必须排除，并且不会从该K线之后重新补足15根。
25. 触碰与入场：候选K线满足 `low <= 白线价格 <= high` 即视为触碰，实体、上影线、下影线或刚好相等都有效。只把按时间顺序第一根触碰白线的K线标记为“入场”，后续重复触碰不再增加标记；剩余观察窗口没有触碰时，保留白线但不产生真正入场标记。
26. 三阶段含义：完整顺序是“回调触发 -> 首次方向反应范围 -> 四分之一白线首次触碰即真正入场”。60分钟突破、回调事件、数量、所属K线和原标记位置不因5分钟真正入场结果而改变。
